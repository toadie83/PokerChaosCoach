Start broadcasting

MediaMTX bridges OBS to this browser tab entirely on your machine.

  1. Run npm run stream in the frontend folder.
  2. In OBS, choose WHIP as the stream service.
  3. Paste the URL below, leave the token blank, and start streaming.
http://127.0.0.1:8889/mystream/whip

Local only. The media, status, and viewer ports are bound to loopback and are not exposed to your network.
