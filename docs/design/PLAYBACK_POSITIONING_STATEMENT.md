# Positioning Statement (Internal Product Direction)

Playback Poker is evolving from a generic AI hand reviewer into an AI-assisted tournament hand replay coach.

The system will no longer generate large monolithic reviews for entire hands.

Instead, it will analyze poker hands as a sequence of strategic decisions across each street.

Every street becomes its own coaching node containing:

- structured metrics
- strategic context
- action evaluation
- concise educational takeaways

This architecture creates:

- clearer coaching
- better user engagement
- more scalable AI costs
- replay-ready infrastructure
- a much more modern poker study experience

Playback Poker should feel less like "reading an AI paragraph"
and more like "exploring a strategic hand replay timeline."
